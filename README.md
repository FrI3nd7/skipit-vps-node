## 💡 О проекте

**SkipIt Tool** — это универсальная интерактивная консольная панель (TUI) и набор инструментов на Bash для автоматизации развертывания, защиты и администрирования VPS-серверов.

Забудьте про рутину:
* 🐳 **Никакого ручного ковыряния в Docker Compose** — скрипт сам развернёт связку с Nginx.
* 🌐 **Интеграция с Cloudflare API** — автоматический выпуск и продление SSL-сертификатов.
* 🚪 **Безопасная смена SSH-портов** — встроенный защитный алгоритм в фоне проверяет соединение, предотвращая случайную блокировку.

## 🛠 Возможности панели

### ⚙️ 1. Ядро Linux и Сетевые Твики (`sysctl`)
- **Оптимизация производительности**:  
  - Настройка TCP-стека с поддержкой алгоритма контроля перегрузки **BBR**.
  - Управление дисциплинами очередей пакетов (`fq` для минимальной нагрузки на CPU или `CAKE` для честного распределения канала и борьбы с буферблотом).
- **Безопасное управление параметрами**:  
  - Предустановленные профили оптимизации с предпросмотром.
  - Ручное редактирование через `nano` или полный сброс к дефолтным значениям системы.
- **Управление IPv6**:  
  - Мониторинг статуса и адресов, быстрое переключение основного интерфейса или отключение.

### 🛡 2. Безопасность и Доступ
- **Тонкая настройка SSH**: Смена порта с проверкой через `sshd -t` и автооткатом при ошибках, управление `root`-доступом и паролями.
- **Управление пользователями**: Создание аккаунтов, генерация паролей, выдача/отзыв прав `sudo`, безопасное удаление.
- **Импорт SSH-ключей**: Ручная вставка (`ed25519`/`rsa`), подтяжка с **GitHub** (`github.com/<user>.keys`), копирование из локальных файлов.
- **Интеллектуальный Fail2ban**: Защита от брутфорса, отслеживание рецидивистов и пресечение сканирования портов.

### 🧱 3. Сеть и Брандмауэр
- **Управление UFW**: Открытие/закрытие портов, просмотр правил, контроль статуса и IPv6.
- **Фильтрация трафика**: Блокировка IP-адресов и подсетей, настройка политик по умолчанию и сброс правил.

### 📊 4. Диагностика, Мониторинг и Утилиты
- **Мониторинг (`btop`)**: Быстрый запуск системного монитора ресурсов.
- **Тесты и проверка сети**: Замер скорости через **Speedtest CLI (Ookla)** и проверка геопозиции IP (`ipregion`) по базам и сервисам (YouTube, Netflix, ChatGPT, Cloudflare).
- **Обслуживание**: Безопасное обновление пакетов системы и очистка диска (кэш apt, неиспользуемые Docker-образы, временные файлы SkipIt).
